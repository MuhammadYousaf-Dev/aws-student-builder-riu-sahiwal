About our group

What is AWS Student Builder Group RIU Sahiwal?

AWS Student Builder Group RIU Sahiwal (AWS SBG RIU Sahiwal) is a student-run cloud computing community at Riphah International University, Sahiwal Campus in Sahiwal, Punjab, Pakistan. It runs sessions, workshops and projects on AWS, cloud computing, Git and GitHub, and building with Kiro.

The group is based at Riphah International University, Sahiwal Campus, Sahiwal, Punjab, Pakistan. The first session, AWS Starting Point, takes place in the University Auditorium.

About AWS Student Builder Groups

What are AWS Student Builder Groups?

AWS Student Builder Groups are student-led communities where post-secondary students and independent learners explore, create and innovate with AWS. The program was previously called AWS Cloud Clubs, and AWS says the community spans 600+ colleges and universities across 63 countries.

Learn more: AWS Builder Center

How do I find or start an AWS Student Builder Group?

You can search for a group near you on AWS Builder Center. If your campus has no group, AWS invites interested students to apply to launch a new AWS Student Builder Group.

Learn more: AWS Builder Center

AWS basics

What is AWS (Amazon Web Services)?

AWS is Amazon’s cloud computing platform. It lets you use computing power, storage, databases, networking, AI and many other services over the internet and pay for what you use, instead of buying and running your own servers.

Learn more: AWS Documentation

What is cloud computing?

Cloud computing means using computing resources such as servers, storage and databases over the internet on demand, instead of owning and maintaining physical hardware.

Do I need coding experience to start learning AWS?

No. You can learn cloud fundamentals from scratch. Some programming knowledge helps once you start building projects, and our sessions are planned to be beginner-friendly.

Getting started with AWS

Is AWS free for students and new users?

New AWS accounts choose between a Free plan and a Paid plan. According to AWS, new customers get $100 in Free Tier credits at sign-up and can earn up to $200 by completing onboarding activities, and more than 30 services have always-free offers. A Free plan account runs for up to 6 months or until the credits are used. AWS updates these terms, so check the AWS Free Tier page before signing up.

Learn more: AWS Free Tier

How do I avoid unexpected AWS charges?

Choose the Free plan when you sign up, set up AWS Budgets and billing alerts, and shut down resources you are not using. On a Paid plan, billing continues at standard rates after your credits are used.

Learn more: AWS Free Tier

Where can I learn AWS for free?

AWS Skill Builder offers free digital training, including the Cloud Practitioner Essentials course, and AWS Documentation and AWS Builder Center have guides and tutorials. You can also attend our sessions.

Learn more: AWS Skill BuilderAWS Training

What is the AWS Certified Cloud Practitioner exam?

AWS Certified Cloud Practitioner (exam code CLF-C02) is AWS’s foundational certification. It covers cloud concepts, security and compliance, cloud technology and services, and billing and pricing. It is commonly reported as 65 questions in 90 minutes with a passing score of 700 out of 1000 and an exam fee of about $100. Confirm current details on the official AWS Certification page.

Learn more: AWS Certification

What is AWS Builder Center?

AWS Builder Center is AWS’s hub for builders. It has articles and guides, community content and a way to find AWS Student Builder Groups.

Learn more: AWS Builder Center

Our planned sessions: Git, GitHub and Kiro

What is Git and what is GitHub?

Git is a version control system that tracks changes to your code. GitHub is a platform for hosting Git repositories and collaborating with others, and GitHub Pages can host static websites. Our second session is an introduction to Git and GitHub.

Learn more: GitHub

What is Kiro?

Kiro is an agentic AI development environment from AWS built around spec-driven development: it turns a prompt into structured requirements, design and tasks before generating code. It is available as an IDE and CLI and has a free tier with limited credits. Check kiro.dev for current plans. Our third session is Build with Kiro.

Learn more: Kiro

Official sources
