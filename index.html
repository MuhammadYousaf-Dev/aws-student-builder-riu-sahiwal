About AWS Student Builder Group RIU Sahiwal

AWS Student Builder Group at Riphah International University, Sahiwal Campus (AWS SBG RIU Sahiwal) is a student-run cloud computing community in Sahiwal, Punjab, Pakistan. We run beginner-friendly sessions, hands-on workshops and projects on AWS, cloud computing, Git and GitHub, and AI-assisted development with Kiro, so students of Riphah Sahiwal and nearby universities can learn, build and ship.
